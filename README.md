Lab8: Java Methods and Structure

A Java lab focused on organizing logic in a single source file while reinforcing method-level problem solving.

Highlights
Single-file Java project.
Practices structured program logic.
Reinforces reusable method thinking.
Simple command-line compile and run process.

Overview
Lab8 continues the CS1 progression by emphasizing how code can be organized as assignments become more involved. The project remains compact while reinforcing better structure and readability.
It is intended as practice for moving from one large main method toward cleaner helper methods.

Why This Project
Well-organized code becomes easier to test, debug, and explain. This lab supports that transition while staying within beginner Java concepts.

Usage
Compile: Save the code as Lab8.java and compile using javac Lab8.java.
Run: Execute the compiled code with java Lab8.
Review the console output and source comments to understand the lab flow.

Installation
Ensure you have the Java Development Kit (JDK) installed on your system.
Open a terminal in the lab folder before compiling so the program can find any required local text files.

Architecture
File Structure: The project consists of a single .java file named Lab8.java.
Components: The Java class contains the program's methods and console behavior.
